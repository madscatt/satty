# Planetary Crisis Operations

## Long-term direction

Satty is intended to provide veteran Satisfactory players with relaxing,
long-term, narrative-driven objectives after the vanilla game is complete.
The experience should feel like an official Coffee Stain feature and should
reuse vanilla mechanics wherever practical.

## Design constraint for now

The long-term vision must not drive the first implementation. The first
milestone exists only to prove that a small, maintainable mod can move through
the complete GitHub → Codex → build → package → game → verification loop.

Future design documents can expand this file once the prototype is playable.
